# Cricket Prediction League

Free-to-play prediction leagues for friend groups. Create a private league, predict
match outcomes, and compete on a season-long leaderboard.

This project is also a deliberate, end-to-end walk through the software development
life cycle. Every phase produces a real artifact, and every artifact lives in this repo.

**Target launch:** before the start of IPL 2027 (late March 2027)
**Time budget:** 10–12 hours per week

## Constraint that shapes everything

Under India's Promotion and Regulation of Online Gaming Act, 2025, real-money online
games are prohibited. This product is **free to play: no entry fees, no cash prizes,
no paid rewards.**
